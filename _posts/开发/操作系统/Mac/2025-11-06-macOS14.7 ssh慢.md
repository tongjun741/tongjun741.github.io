Linux下可以关闭tso解决问题：

```
ethtool -K <interface> tso off
```



在 macOS 中，没有 `ethtool` 工具，但可以通过系统内置的命令实现类似 `ethtool -K <interface> tso off`（关闭 TSO 功能）的操作。以下是具体方法：

### 什么是 TSO？

TSO（TCP Segmentation Offload）是一种网络硬件加速技术，允许网卡而非 CPU 处理 TCP 数据包分片，提升传输效率。但在某些场景下（如特定网络环境、虚拟化或调试），可能需要关闭 TSO。

### macOS 中关闭 / 开启 TSO 的操作

#### 1. 确认网络接口名称

首先查看你的网络接口名称（如有线网卡通常为 `en0`，无线为 `en1` 或 `en2`）：

```bash
ifconfig
```

找到你正在使用的接口（如 `en0` 对应 “以太网”，`en1` 对应 “Wi-Fi”）。

#### 2. 关闭 TSO

使用 `sysctl` 命令临时关闭指定接口的 TSO（需管理员权限）：

```bash
# 替换 en0 为你的接口名称
sudo sysctl -w net.inet.tcp.tso=0
sudo sysctl -w net.inet.udp.tso=0  # 若需要同时关闭 UDP 的 TSO（部分场景）
```

- `net.inet.tcp.tso=0`：关闭 TCP 的 TSO 功能（核心参数，对应 `ethtool` 的 `tso off`）。
- 该设置立即生效，但重启后会恢复默认值。

#### 3. 永久关闭 TSO（可选）

若需重启后保持设置，需将配置写入系统配置文件：

```bash
# 创建或编辑 sysctl 配置文件
sudo vi /etc/sysctl.conf
```

添加以下内容（替换 `en0` 为你的接口名称，若不确定可直接全局关闭）：

```bash
net.inet.tcp.tso=0
net.inet.udp.tso=0
```

保存退出后，配置会在下次重启时生效。

#### 4. 验证 TSO 状态

检查 TSO 是否已关闭：

```bash
sysctl net.inet.tcp.tso
```

若输出 `net.inet.tcp.tso: 0`，说明 TSO 已关闭（`1` 表示开启）。

### 补充说明

- macOS 的网络参数控制方式与 Linux 不同，没有像 `ethtool` 那样细粒度的接口单独配置，`sysctl` 命令的设置通常是全局生效的（对所有接口）。
- 若仅需临时测试，建议使用临时关闭命令（无需修改配置文件），测试完成后可通过 `sudo sysctl -w net.inet.tcp.tso=1` 重新开启 TSO。

通过以上步骤，可在 macOS 中实现与 Linux `ethtool -K <interface> tso off` 等效的功能。
